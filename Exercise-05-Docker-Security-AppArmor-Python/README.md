# Exercise 5: Docker Security Using AppArmor and Python

## 📌 Overview

This project demonstrates Docker container security using AppArmor and Python automation. A Flask web application is containerized using Docker, and Python scripts are used to launch containers with security options and test restricted actions.

The objective is to explore how AppArmor can help restrict application behavior and improve container security.

## 🎯 Objectives

- Create a Flask web application.
- Containerize the application using Docker.
- Configure an AppArmor security profile.
- Automate Docker container creation using Python.
- Test restricted actions inside a container.
- Document the implementation and testing process.

## 🛠️ Technologies Used

- Python
- Flask
- Docker
- AppArmor
- Docker SDK for Python
- Git and GitHub
