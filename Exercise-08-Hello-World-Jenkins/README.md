# Exercise 8: Creating a Hello World Jenkins Job

## Objective

To create and execute a simple shell script using Jenkins.

## Technologies Used

- Jenkins
- Git
- GitHub
- Bash

## Project Description

This exercise demonstrates how to store a shell script in GitHub
and execute it through a Jenkins Freestyle project.

## Script

The `hello-world.sh` script prints:

Hello, Jenkins!

## Expected Result

The Jenkins build should complete successfully and display
`Hello, Jenkins!` in the Console Output.
